# Examples

公开仓库默认不附带真实课程、项目或论文图，以避免泄露用户材料和违反第三方图片许可。

运行测试时，`tests/`会在临时目录中生成无版权的最小PPTX、PNG和CSV，用于证明：

- 合格PPT能够通过；
- 图片裁剪、重复使用和禁用措辞能够被拦截；
- 缺失文件、错误哈希和未核验状态能够被拦截；
- 公式渲染、缩略图总览和交付哈希比较能够执行。

[`five_slide_academic_demo`](five_slide_academic_demo/) 是一个可直接打开和重新生成的五页示例。它以空白16:9画布构建，只含原创文字和原生PowerPoint对象，不含机构模板、个人信息、真实项目材料或第三方科研图。

建立真实示例时，只提交项目自有或明确允许再分发的素材。第三方论文图建议只提交元数据和获取说明。
