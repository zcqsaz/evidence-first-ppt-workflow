## 3. 来源元数据集成测试

对23行真实素材元数据执行本地文件与可选网络检查：

- 23/23个文件存在；
- 23个文件SHA-256互不重复；
- 元数据Schema和核验状态无错误；
- 网络访问没有作为科学真实性证明；
- 测试时两个出版商文章URL返回HTTP 403，一个被登记为下载地址的页面返回HTML MIME，均作为可追踪警告保留。

出版社反爬造成的HTTP警告不会抹去本地已保存的来源、DOI、图号和文件证据，也不能被静默忽略。正式项目应按失败报告规范记录网络限制和替代核验路径。

## 4. 仍需人工完成的验证

自动测试不能证明：

- 原图在取得之前没有被人为截断；
- 图中变量、时间、单位和区域解释正确；
- 第三方素材获得了足够的使用许可；
- 字号、公式和多面板图在实际教室或会场中可读；
- 页面结论在学术上成立；
- 动画、视频和特殊字体在目标电脑上正常。

这些项目仍属于五至八轮人工复核和最终批准人的职责。
