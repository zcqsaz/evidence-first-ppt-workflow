# Institutional template and visual layout standard

## 1. 使用真实模板

用户指定机构模板时，必须直接使用该模板或用户确认的母版文件。只模仿颜色、Logo或背景纹理不等于使用模板。

## 2. 模板分析记录

`template_analysis.md` 至少记录：

- 页面宽高与比例；
- 顶部/底部母版区域；
- Logo、箭头、装饰纹理；
- 标题安全区；
- 正文有效区；
- 页脚安全区；
- 页码位置；
- 字体与配色；
- 需统一删除或遮罩的母版框；
- 参考PPT中用户认可页面的几何尺寸。

## 3. 标题

- 标题位于正文白区，不进入顶部母版带；
- 不与Logo、箭头或纹理重叠；
- 长标题优先精炼或增加标题框高度；
- 不通过上移越界解决换行；
- 章节名与母版导航元素基线对齐。

## 4. 页码与页脚

- 页码中心必须等于页面宽度几何中心；
- 页码不以正文区或视觉剩余区为中心；
- 页脚和页码上下分离；
- 页脚不穿过页码；
- 若母版右下角框不适用，应统一处理全部正文页。

## 5. 图片

- 科研图使用等比完整显示；
- 不使用 `cover/crop` 填满；
- 非定量实景照片可裁剪，但需记录例外并确认主体完整；
- 图题紧邻图片；
- 不给论文图套低级卡片框；
- 多面板图必须在放映尺寸可读。

## 6. 排版构图

推荐构图：

1. 图左文右；
2. 图右文左；
3. 全宽图 + 下方三点解释；
4. 公式 + 实证图 + 参数解释；
5. 原生学术表格；
6. 双栏高密度文字；
7. 地图 + 验证；
8. 技术路线 + 关键说明。

选择依据是信息关系，不是轮流套模板。

## 7. 颜色和装饰

- 颜色用于区分层级和重点，不用于制造“科技感”；
- 减少卡片式UI、等宽三栏和大面积浅色框；
- 每页一个视觉中心；
- 线条只承担分隔、对齐和关系表达；
- 不用Logo拼图或无意义图标填空。

## 8. 字体

- 使用项目指定字体并审计所有可编辑文字；
- 标题、正文、图题、页脚分别设置最低字号；
- 不用缩小字号解决内容结构问题；
- 数学公式的字体由数学排版引擎控制；
- 公开发布前确认字体嵌入和许可。
