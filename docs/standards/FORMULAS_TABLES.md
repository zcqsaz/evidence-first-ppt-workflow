# Formula and academic table standard

## 1. 公式必须数学排版

以下内容不得用普通文本模拟：

- 分式；
- 求和与积分；
- 复杂上下标；
- 指数与多层括号；
- 导数、矩阵和优化目标；
- 向量与张量。

## 2. 推荐公式流程

```text
LaTeX/mathtext源代码
→ 透明背景高分辨率PNG或SVG
→ 独立检查
→ 等比插入PPT
→ PowerPoint实际渲染复查
```

推荐保留 `formula_id → latex_source → output_file → ppt_page` 映射。

## 3. 逐式检查

- 分子和分母；
- 括号层级；
- 上下标对象；
- 求和/积分上下限；
- 导数阶数；
- 希腊字母；
- 向量/矩阵粗体；
- 长公式是否被压缩得不可读；
- PNG/SVG是否被裁剪。

## 4. 公式页内容

公式页不能只有公式。至少包括：

- 公式表达什么；
- 每个关键符号的意义；
- 参数如何影响结果；
- 适用条件；
- 错误来源或局限；
- 方法来源。

## 5. 正文变量

简单变量可以使用正确的Unicode上下标或中文解释。禁止保留 `z_i`、`a_1` 等源码字符串。复杂表达仍使用数学排版。

## 6. 学术表格

表格适合：

- 方法比较；
- 指标矩阵；
- 数据字段；
- 质量控制；
- 决策规则；
- 计划和目标。

不适合把普通列表机械改成表格。

## 7. 表格样式

- 使用PPT原生表格；
- 表头清晰；
- 必要的顶线、表头线和行分隔线；
- 数字、单位和小数位一致；
- 文本列左对齐，数字列按语义对齐；
- 不把表格截图套进卡片框；
- 避免每页都用表格。

## 8. 表格QA

- 单元格文字不溢出；
- 行高能容纳换行；
- 不出现被截断的末行；
- 表头与正文有清晰层级；
- 表格结论在页内明确回收；
- 来源写入页脚。
