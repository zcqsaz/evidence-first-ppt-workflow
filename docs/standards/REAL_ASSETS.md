# Real scientific asset retrieval and audit standard

## 1. 核心原则

> 先建立文献证据链，再下载图片；先确认图片是什么，再决定放在哪一页。

本标准适用于论文图、官方产品图、地图、时间序列、验证图、流程图、平台截图、卫星/仪器照片和现场照片。

## 2. 强制交付物

每个素材集合至少包含：

```text
04_real_assets/
├── publisher_originals/
├── official_originals/
├── references/
├── access_log.csv
├── source_metadata.csv
├── retrieval_report.md
├── usage_notes.md
└── contact_sheet.jpg
```

只交付图片文件、不交付证据登记，视为未完成。

## 3. 来源优先级

### Tier 1：官方机构和产品门户

适合：卫星、仪器、项目区、产品地图、平台界面、现场照片、用户指南。

### Tier 2：同行评议论文出版商原图

适合：方法流程、时间序列、参数敏感性、验证、产品结果和不确定性。

优先顺序：

```text
SVG/TIFF/出版商原始PNG > 补充材料原图 > 作者机构仓储 > PDF完整图提取
```

出版商原始单图存在时，禁止继续使用PDF页面截图。

### Tier 3：正式报告和技术文档

适合：算法理论基础文档、用户指南、项目报告、技术规范和图集。

### Tier 4：官方数据门户截图

只有没有可下载原图时使用。必须保留数据集名称、时间、图例、单位和区域。

### Tier 5：补充来源

仅前四级无结果时，使用承担单位新闻、高校官网、作者实验室或正式会议报告。

## 4. 禁止来源

- AI生成科研图；
- 搜索引擎缩略图；
- 无来源转载、自媒体重绘或营销海报；
- Pinterest、商业图库或设计社区素材；
- 只有“科技感”但不支撑页面内容的卫星图；
- Logo堆叠；
- 缺少变量、图例、时间或单位的彩色地图；
- 无法证明属于当前项目的相似项目图片；
- 低清图放大；
- 将示意图标成实测产品；
- 将抽样足迹标成连续格网；
- 将树木覆盖损失直接写成永久毁林；
- 将AGB直接写成碳储量。

## 5. 检索流程

### 5.1 锁定核心来源

先回答：

- 正式名称是什么；
- 负责机构是谁；
- 核心论文或报告是什么；
- 产品名称、版本和官方页面是什么；
- DOI或永久链接是什么。

推荐检索：

```text
"正式名称" official paper
"正式名称" product user guide
"正式名称" project documentation
"正式名称" filetype:pdf
"正式名称" site:nasa.gov
"正式名称" site:esa.int
"正式名称" site:gov
"正式名称" site:edu
```

### 5.2 论文内部定位

检索关键词：

```text
Figure, workflow, framework, product, validation, uncertainty,
time series, map, instrument, data flow, study area, sensitivity
```

记录图号、完整图题、页码和页面要支撑的论点。

### 5.3 出版商原图发现

1. 打开论文HTML或检查页面源代码；
2. 查找静态图片、`figure`、`article_deploy/html/images`、`media`或下载按钮；
3. 下载原始文件，不保存浏览器缩略图；
4. 用论文PDF或HTML图题核对图号；
5. 记录直接下载地址与文章永久页面。

MDPI常见原图形式示例：

```text
https://mdpi-res.com/d_attachment/<journal>/<article-id>/
article_deploy/html/images/<article-id>-g00x.png
```

路径只用于帮助定位；不得假设图号或文章ID，必须由正式论文核验。

### 5.4 学术网站受限时的回退

```text
DOI/期刊页
→ 开放全文或补充材料
→ 作者机构仓储/预印本
→ PMC/Europe PMC/HAL/Zenodo/机构知识库
→ 官方产品文档或用户指南
→ 登记为未公开/无法可靠获得
```

禁止回退到搜索引擎缩略图或二次转载。

Elsevier、Springer Nature、Wiley、Taylor & Francis、IEEE等平台的正常访问路由、机构订阅、OA版本、出版社API和403/429/CAPTCHA处置见 [PUBLISHER_ACCESS.md](PUBLISHER_ACCESS.md)。该规范只允许合法访问，不包含绕过付费墙或反爬的方法。

## 6. 每图真实性核验

每张图逐一核对：

| 字段 | 必须回答的问题 |
|---|---|
| 归属 | 确实属于当前项目、论文或产品吗？ |
| 变量 | AGB、SIF、NDVI、LAI、RH100等具体是什么？ |
| 时间 | 单日、月度、年度、多年平均还是变化时期？ |
| 区域 | 全球、国家、流域、样地还是足迹？ |
| 单位 | t ha⁻¹、m、%、mm、K等是什么？ |
| 性质 | 原始观测、反演产品、模型输出、统计推断还是示意？ |
| 版本 | 产品或算法版本是什么？ |
| 图号 | 与论文图题一致吗？ |

证据不足时标记“未核验，不建议用于正式PPT”。

## 7. 完整性核验

### 7.1 源文件完整性

必须保留：

- 全部坐标轴；
- 图例；
- 单位；
- 比例尺和方向；
- 面板编号；
- 地图边界；
- 流程起止节点；
- 解释图所必需的标注。

必须排除：

- 论文正文；
- 残缺图注；
- 页眉页脚；
- 邻近表格或段落；
- 浏览器界面和无关水印。

### 7.2 PPT显示完整性

- 科研图必须按原始比例 `fit`；
- PowerPoint裁剪值为0；
- 不拉伸、不压扁；
- 图太复杂而无法在半页读清时，不得通过裁面板解决；
- 选择更简单的原图、拆成出版商独立面板或安排独立页面。

## 8. 清晰度

推荐最低值：

| 用途 | 长边 |
|---|---:|
| 页面主图 | 1600 px |
| 半页图 | 1000 px |
| 四宫格单图 | 700 px |

低于阈值时继续查找SVG、TIFF、出版商PNG、补充材料或作者原图。不得通过插值放大宣称高清。

## 9. 页面匹配

| 页面类型 | 优先素材 |
|---|---|
| 概述 | 主体身份 + 观测/实施 + 代表性成果 |
| 数据 | 卫星组合、传感器、数据流、观测网络、质量信息 |
| 方法 | 原论文流程、ATBD、处理链、参数敏感性 |
| 结果 | 地图、验证、时间变化、不确定性四类互补证据 |
| 应用 | 真实用户场景、现场核查、管理或政策应用 |
| 验证 | 站点地图、散点、误差、尺度匹配 |
| 总结 | 能概括数据—算法—产品—应用闭环的证据 |

图片只因“相关”不足以上屏，必须直接支撑该页结论。

## 10. 命名、图题与引用

文件名：

```text
序号_内容_来源_年份_图号.扩展名
```

中文图题优先包含：

```text
变量 + 时间 + 区域 + 产品性质 + 单位
```

页内简写：

```text
图源：Author et al., 2024, Fig. 3。
图源：NASA Earthdata，2025。
```

完整参考文献保留在元数据或参考文献页。

## 11. 元数据

最少字段见 `templates/project/04_real_assets/source_metadata.csv`；论文/平台级访问过程见 `templates/project/04_real_assets/access_log.csv`。

`verification_status` 采用以下值：

- `verified`；
- `usable_with_note`；
- `unverified_do_not_use`；
- `not_publicly_available`；
- `not_found`。

## 12. 失败报告

失败不能只写“未找到”。必须记录：

- 失败步骤；
- 实际搜索词；
- 访问页面；
- HTTP状态或错误；
- 直接原因；
- 已尝试措施；
- 可接受替代方案；
- 继续所需条件。

## 13. 版权与公开发布

- 记录授权或合理使用注意事项；
- 不确定能否再分发时，只提交元数据与下载说明，不提交图片文件；
- 公开仓库中的示例使用公共领域、CC许可或合成素材；
- 引用不等于取得版权许可。
