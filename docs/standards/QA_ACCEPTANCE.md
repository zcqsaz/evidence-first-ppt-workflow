# QA and acceptance standard

## 1. 原则

结构检查不能替代放映检查，放映检查也不能替代来源核验。最终验收由三层组成：

1. 内容与证据；
2. PPTX结构与资产；
3. 目标环境实际渲染。

## 2. 自动检查指标

| 指标 | 默认要求 |
|---|---:|
| PPTX可重新打开 | 通过 |
| 页数 | 与规格一致 |
| 对象越界 | 0 |
| 文本框几何重叠 | 0个未批准 |
| 项目符号实际溢出 | 0 |
| 科研图/公式裁剪值 | 0 |
| 科研媒体重复哈希 | 0个未批准 |
| 禁用措辞 | 0 |
| 显式非目标字体 | 0 |
| 严格资产来源映射 | 100% |
| 元数据必填字段 | 100% |
| 正式/交付文件哈希 | 一致 |

重复出现于绝大多数页面、且几何位置一致的Logo或模板图片可配置为母版例外。

## 3. PowerPoint全量渲染

- 使用目标PowerPoint版本或正式放映环境；
- 导出全部页面，建议1600×900；
- 生成缩略图总览；
- 检查页面缺失、字体替换、公式损坏、图片裁断和动画静态结果；
- 重点页以原始分辨率查看。

## 4. 图片人工检查

每幅图确认：

- 全部面板；
- 坐标轴；
- 图例；
- 单位；
- 图题；
- 页脚来源；
- 与本页论点一致；
- 最终尺寸可读；
- 没有正文碎片。

## 5. 公式人工检查

逐式与LaTeX源代码对照。重点检查分式、括号、上下标、求和范围、导数、粗体和希腊字母。

## 6. 信息密度检查

正文页应回答：

- 这一页明确要证明或解释什么；
- 有几条实质知识点；
- 图/公式/表格承担什么证据任务；
- 适用边界在哪里；
- 是否存在可明显补充内容却保留的大面积空白。

## 7. 同质化检查

查看缩略图总览，检查：

- 相邻页主图位置是否机械重复；
- 是否连续使用同一种卡片/三栏；
- 是否同一图片多次出现；
- 是否所有页面都由表格构成；
- 是否每页都有清晰主视觉。

## 8. 五至八轮复核记录

每轮记录：

```text
检查范围：
发现问题：
证据：
修改动作：
修改文件：
复查结果：
剩余风险：
```

## 9. 失败分级

- **Blocker**：图片不完整、公式错误、事实错误、文件打不开、版本不一致；
- **Major**：信息密度不足、文字重叠、图文错配、来源缺失、标题越界；
- **Minor**：个别换行、间距、标点和图题措辞；
- **Advisory**：不影响交付的改进建议。

Blocker和Major必须归零；Minor必须记录并由批准人接受。

## 10. 验收报告

最终报告至少包含：

- 文件路径和SHA-256；
- 页数；
- 工作流版本；
- 素材数量与来源状态；
- 公式数量；
- 自动检查结果；
- 渲染目录；
- 人工抽查页；
- 例外和已知限制；
- 批准人和日期。
