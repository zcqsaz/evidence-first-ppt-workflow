# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-07-23

- Initial open-source release.
- Defined evidence-first stage gates and artifact contracts.
- Added standards for publisher-original figures, formulas, academic tables,
  content density, institutional templates, and delivery QA.
- Added reusable project templates and JSON Schemas.
- Added PPTX, source metadata, formula rendering, contact sheet, project
  initialization, and PowerPoint rendering utilities.
- Added delivery hash comparison, JSON validation reports, cross-platform tests,
  GitHub Actions QA, wheel-packaged schemas/templates, and an open-source
  privacy/copyright release checklist.
