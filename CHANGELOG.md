# Changelog

All notable changes to this project will be documented in this file.

## 1.0.2 - 2026-07-24

- Added a five-slide, editable academic-PPT example built from a blank 16:9
  canvas: cover, agenda highlight, page specification, asset audit, and QA.
- The committed example contains only original workflow content and native
  PowerPoint objects; it contains no institutional template, logo, personal
  information, real project material, or third-party research figure.
- Added a regression test and local-artifact exclusions for the example.

## 1.0.1 - 2026-07-24

- Added a compliant publisher-access standard covering Elsevier/ScienceDirect,
  Springer Nature, Wiley, Taylor & Francis, SAGE, IEEE/ACM and open platforms.
- Added DOI metadata and lawful open-access candidate resolver using Crossref,
  OpenAlex and optional Unpaywall discovery; it never downloads or bypasses
  restricted content.
- Added paper-level access logging and access/rights metadata fields for assets.

## 1.0.0 - 2026-07-23

- Initial open-source release.
- Defined evidence-first stage gates and artifact contracts.
- Added standards for publisher-original figures, formulas, academic tables,
  content density, institutional templates, and delivery QA.
- Added reusable project templates and JSON Schemas.
- Added PPTX, source metadata, formula rendering, contact sheet, project
  initialization, and PowerPoint rendering utilities.
- Added delivery hash comparison, JSON validation reports, cross-platform tests,
  GitHub Actions QA, wheel-packaged schemas/templates, and an open-source
  privacy/copyright release checklist.
